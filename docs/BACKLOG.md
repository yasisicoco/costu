## 사용자 승인 기능: 얼굴 비공개 카메라 아바타 연동

사용자가 표정·고개 움직임을 카메라로 읽어 아바타에 반영하는 방식을 선택했다. 기본 집중은 카메라 없이 사용하고, 카메라 연동은 기본 꺼짐·직접 켜기·언제든 끄기를 유지한다. 얼굴 영상 비전송과 같은 서재에 전달하는 움직임 수치를 구분해 안내한다.

- [x] 사용자 선택과 선택형 카메라·개인정보·타이머 독립 계약을 PRD에 반영
- [x] 버튼을 누를 때만 권한 요청, 새로고침·탭 복귀 시 자동 재활성화 방지
- [x] 추론 라이브러리·모델을 같은 Origin에서 제공
- [x] 기기 내 표정·고개 동작 추정과 내 아바타 표현 구현
- [x] 같은 서재에 정규화된 yaw/pitch/roll·눈·입·미소 값만 동기화
- [x] 원본 영상·전체 랜드마크·얼굴 식별 정보의 저장·전송 없음 확인
- [x] 감정·집중도·신원 추론 및 타이머·자리 비움 자동 변경 없음 확인
- [x] 끄기·오류·권한 거부·탭 백그라운드·장치 종료 시 스트림 해제와 중립 아바타
- [x] 켜기 도중 취소한 뒤 늦게 도착하는 스트림도 해제
- [x] 인식 실패·오래된 동작 값·서버 단절 시 중립 아바타, 개인 타이머 유지
- [x] 두 브라우저 동기화·서재 격리·권한 정책·기존 타이머 회귀 검증
- [x] 생성 영상·가짜 카메라 테스트 스냅샷을 실제 인식 품질 검증과 구분
- [ ] 실제 iOS Safari·Android Chrome에서 표정·고개 인식과 발열·배터리·화면 잠금 복귀 확인

카메라 기능 구현 승인은 실제 호스팅 실행, 새 유료 자원, 공개 범위 변경 승인이 아니다. Render 등 배포는 화면 검토 이후 별도로 다룬다.

사용자가 승인한 기능 개선과 고장·접근성·실기기 검증을 함께 진행한다. 외부 분석 SDK, 유료 API, 음성, 공개방을 자동으로 도입하지 않는다.

## 반복 검증 명령

```sh
npm ci
npm run check
npx playwright install --with-deps chromium
npm run test:e2e
npm audit
```

현재 Cloud에서는 브라우저 CDN이 차단되어 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`로 실행한다.

`--with-deps`는 Cloud/Linux에서 브라우저 실행 라이브러리를 준비할 수 있는 환경에 사용한다. 로컬 Windows는 `npx playwright install chromium`으로 검증했다.
