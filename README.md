# costu

얼굴 공개 없이, 친구와 같은 공간에 있는 것처럼 공부하는 집중 앱의 초기 MVP.

## 실행

Node.js 22.12 이상을 기준으로 개발했다.

```sh
npm ci
npm run dev
```

- 개발 화면: http://localhost:5173
- 실시간 서버: http://localhost:3001
- 빌드 실행: `npm run build` 후 `npm start`, http://localhost:3001
- `PORT`로 배포 서버 포트 변경 가능. 개발 프록시는 3001 사용.
- 다른 Origin을 분리해서 운영한다면 `ALLOWED_ORIGINS`에 정확한 Origin을 쉼표로 구분하여 지정.

## 구현 기능

- 1–120분 개인 타이머, 일시 정지·재개·종료, 새로고침 복원
- 집중 기록 후 선택해서 시작하는 5분 휴식, 일시 정지·복원·건너뛰기 (공부 시간에 미합산)
- 공부할 일·목표 분량 저장, 선택한 할 일로 바로 집중, 실제 기록에 따른 진행률·목표 달성
- 휴대폰 공유 시트로 친구 초대, 링크 복사 대안
- 기록·설정 화면의 진행 중 타이머 안내와 집중 화면 복귀
- 로컬 공부 기록, 하루 목표, 최근 7일 차트, 기록·할 일 JSON 백업 내보내기·불러오기
- 4종 아바타 및 닉네임 설정
- 8자리 코드·링크 기반 비공개 초대형 서재, 최대 6명
- 실제 참가자의 집중·자리 비움 상태 및 응원 리액션 동기화
- 네트워크 단절 시 30초 재접속 유예, 복귀 시 최신 집중·일시 정지·휴식 상태 동기화
- 연결 복구 확인 전 서재 조작 차단, 오프라인 퇴장 의사 보존
- 모바일 본문·대비 개선, 최소 44px 터치 영역
- Web Audio로 생성하는 선택형 바람 배경음
- 반응형 화면, 키보드 모달, 동작 줄이기 설정 대응
- 프로덕션 빌드를 한 번 온라인으로 연 뒤 오프라인 개인 집중 지원

## 검증

```sh
npm run check
npx playwright install chromium
npm run test:e2e
npm audit
```

Cloud에 사전 설치된 Chromium을 사용할 때는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`로 실행한다. 이 환경에서는 Playwright CDN 다운로드가 네트워크 정책으로 차단되어 사전 설치 브라우저로 검증했다.

`test:e2e`는 먼저 빌드하고 개발 서버를 자동 실행한다. 5173·3001 포트가 필요하다. 스크린샷은 `test-results/`에 생성된다. 프로덕션 서비스워커는 localhost 또는 HTTPS에서 작동한다.

## 데이터와 한계

공부 기록과 타이머는 해당 Origin의 localStorage에 저장한다. 개발 서버와 프로덕션 서버의 Origin이 다르면 기록도 별개다. 여러 탭은 같은 Origin의 타이머를 공유한다. 날짜 통계는 기기 현지 시간 기준이며 자정을 넘긴 세션은 종료일에 합산한다. 함께 공부 분류는 세션 중 서재에 참여한 경우를 포함하며, 함께한 시간만 정확하게 분리 계산하지 않는다.

서재는 단일 Node.js 프로세스 메모리에 저장한다. 명시적으로 마지막 사용자가 나가거나 재접속 유예가 끝나면 제거된다. 서버 재시작 시 서재는 사라진다. 로그인, 클라우드 기록 동기화, 카메라 존재 감지, 음성, 공개방, 푸시는 아직 구현하지 않았다. 초대 코드를 아는 사람은 입장할 수 있으므로 초대 코드를 계정 인증으로 간주하지 않는다.

실시간 협업은 같은 서버에 연결해야 한다. `localhost` 링크는 다른 사람의 기기에서 공유할 수 있는 서비스 주소가 아니다. 휴대폰 실기기, iOS Safari, Android Chrome 및 앱스토어 패키지는 별도 검증 전이다.

카메라·마이크를 요청하거나 영상·음성을 전송하지 않는다. 외부 분석·광고 SDK도 없다. 폰트와 그래픽은 로컬 제공한다.
